Prima3 Pomphuis

Build guide (README) · GitHub

Pump house and irrigation controller: fills a water tank from a borehole, runs 9 irrigation zones through 7 solenoid valves, drives the tank filter pump and keeps track of two households sharing one borehole — on a WEMOS LOLIN S3 Mini (ESP32-S3). Everything runs in a web page on your own WiFi.

Install on a new S3 Mini

Firmware version: …

Use Chrome or Edge on a PC or Mac — this browser cannot flash over USB.
  1. Plug the S3 Mini into the PC with a USB data cable and press CONNECT above.
  2. If no port shows up: hold BOOT (0), tap RST, release BOOT, and try again.
  3. Choose Erase for a new board, then Install (about a minute).

First start: choose your WiFi

  1. The new controller opens its own WiFi hotspot Prima3-Setup (the LED blinks red fast).
  2. Connect a phone to it — the setup page opens by itself (otherwise browse to http://192.168.4.1/).
  3. Pick your network, type the password and give it a fixed IP, press SAVE & RESTART.
  4. Put the phone back on your normal WiFi and open the fixed IP (or http://primapomphuis.local/).

More networks: SETTINGS → WiFi Networks lists them with DELETE and ADD NETWORK (passwords are never shown). The controller tries the saved networks in range, strongest first — and when several access points share one network name (mesh / multi-AP), the strongest of them. Hold BOOT while powering up to open the setup hotspot again; it also opens by itself for 5 minutes when no network can be reached.

Updates

On the controller's ABOUT page: CHECK FOR UPDATE compares its version with the one on this site; INSTALL FROM GITHUB downloads and installs it (not while a zone irrigates or the borehole pump runs). Settings and logs are kept, and a failed download leaves the old firmware running.

No internet at the controller? Download prima3.bin and use UPLOAD & INSTALL on the ABOUT page.

Works with the Rain Gauge

Tick Use Rain Gauge on SETTINGS and enter the gauge's IP: the controller asks a Rain Gauge every hour whether to irrigate today. Then set Respect Rain Gauge Recommendation = Yes on IRRIGATION for every zone that must follow the gauge — a zone set to No waters whatever the gauge says.
